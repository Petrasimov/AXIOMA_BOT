# AXIOMA BOT

Telegram-бот проекта **[AXIOMA SCAN](https://axioma-scan.ru)** — криптовалютного
CEX-CEX арбитражного сканера.

Бот рассылает уведомления о новых арбитражных возможностях и обслуживает
пользователей: подписка, поддержка, вакансии.

---

## Возможности

**🔔 Уведомления об арбитраже**
Каждую минуту проверяет новые возможности и рассылает их пользователям
по их же фильтрам из настроек сканера — стратегия, минимальный спред,
разрешённые биржи. Антиспам: не чаще раза в час по одной связке, повторно —
только если спред успел упасть и вырасти снова.

**💳 Оплата подписки**
Криптовалютой через NOWPayments. Пять монет и сетей, QR-код, автоматическая
выдача доступа после подтверждения. Платёж не теряется при перезапуске бота.

**💬 Поддержка**
Обращение уходит карточкой в чат администраторов. Админ отвечает реплаем —
бот пересылает ответ пользователю от имени поддержки, анонимно.

**👥 Вакансии и резюме**
Список открытых позиций, приём резюме одним сообщением в чат администраторов.

**🔑 Восстановление пароля** — в разработке.

## Быстрый старт

```bash
git clone https://github.com/Petrasimov/AXIOMA_BOT.git
cd AXIOMA_BOT

pip3 install -r requirements.txt

cp .env.example .env
nano .env          # заполнить BOT_TOKEN и DATABASE_URL

python3 main.py
```

Бот поднимется, даже если заполнены только `BOT_TOKEN` и `DATABASE_URL` —
разделы, которым не хватает настроек, честно сообщат об этом, а не сломают
весь процесс.

## Конфигурация

Все настройки в `.env`, шаблон — `.env.example`.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `DATABASE_URL` | да | Строка подключения к PostgreSQL |
| `ADMIN_CHAT_ID` | для поддержки | Чат администраторов. Для супергруппы ID отрицательный |
| `NOWPAYMENTS_API_KEY` | для оплаты | Ключ NOWPayments |
| `SCANNER_URL` | нет | Ссылка на сканер в кнопках |
| `CHECK_INTERVAL` | нет | Интервал проверки возможностей, секунды (60) |
| `COOLDOWN_HOURS` | нет | Пауза между уведомлениями по одной связке (1) |
| `MAX_NOTIFICATIONS_PER_CYCLE` | нет | Лимит сообщений одному пользователю за цикл (5) |
| `SUBSCRIPTION_PRICE_USD` | нет | Стоимость подписки (5) |
| `PAYMENT_TIMEOUT_MINUTES` | нет | Время на оплату (30) |

⚠️ `.env` не коммитится — он в `.gitignore`.

## Как это устроено

**Один процесс, две задачи.** `asyncio.gather` крутит цикл уведомлений
и приём входящих параллельно. Общий пул соединений с БД, общая HTTP-сессия.

**Приём через long-polling.** Не требует HTTPS-эндпоинта и правки конфига
nginx боевого сайта.

**Состояние диалогов не хранится.** Bot API не помнит контекст — приходит
просто `{user_id, text}`. Вместо своей таблицы состояний используется
`ForceReply`: бот задаёт вопрос, пользователь отвечает реплаем, и в апдейте
приходит текст вопроса. Хранилищем работает Telegram — переживает любой
рестарт.

Тот же приём в поддержке: ID пользователя живёт в тексте карточки
и в `callback_data` кнопки.

**Свои данные — одна таблица.** `NotificationCooldowns`, создаётся ботом
при старте через `CREATE TABLE IF NOT EXISTS`. Остальные таблицы принадлежат
C#-бэкенду, бот их только читает. Исключение — `Users.IsCexCexPaid` при
успешной оплате.

**История платежей не ведётся.** Хранилищем работает NOWPayments, связь
платежа с пользователем держится через `order_id` вида `axioma_{user_id}_{ts}`.

## Деплой

```bash
cd /home/axioma/axioma_bot
git pull origin main
pip3 install -r requirements.txt

sudo cp axioma-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl restart axioma-bot

journalctl -u axioma-bot -f
```

Ожидаемые строки при старте:

```
[TG] Бот подключён: @...
БД подключена, таблица NotificationCooldowns готова
[UPDATES] Long-polling запущен
[NOTIFY] Сервис уведомлений запущен
```

⚠️ **Только один экземпляр бота на токен.** `getUpdates` эксклюзивен: если
тем же токеном поллит кто-то ещё, Telegram вернёт `409 Conflict` и бот
перестанет принимать сообщения. Старый юнит `axioma-notifications` должен
быть отключён и удалён.

## Статус

Работают: уведомления, оплата, поддержка, вакансии.

В разработке:

- **Восстановление пароля** — ждём формат хранения от бэкенда
- **Срок действия подписки** — нужна колонка `Users.PaidUntil`; пока её нет,
  доступ выдаётся без срока. Бот определяет наличие колонки при старте
  и работает в обоих режимах
- **Webhook от NOWPayments** — сейчас опрос статуса
